# 🎙️ Voice AI Assistant with Flask, GPT-4o, Whisper, and ElevenLabs

This project is a full-stack voice-based assistant that takes spoken input from the user, transcribes it using OpenAI's Whisper, generates a response with Azure OpenAI GPT‑4o, and then synthesizes the response into speech using ElevenLabs.

## 🚀 Features

- 🎤 **Speech Recognition** using OpenAI's Whisper
- 🧠 **Conversational AI** powered by Azure OpenAI GPT‑4o
- 🔊 **Realistic Speech Synthesis** via ElevenLabs
- 🌐 **Flask Web Server** for easy deployment and testing
- ✅ Built-in deployment test endpoint

## 🛠️ Tech Stack

- Python (Flask)
- Azure OpenAI (GPT‑4o)
- OpenAI Whisper (speech-to-text)
- ElevenLabs (text-to-speech)
- HTML (Frontend)
- REST APIs
